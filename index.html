🎨 Mise en forme

4. Texte

Zone de texte libre, sauvegardée sur GitHub comme le reste de l'application.

5. Résultat (Code HTML)

Code HTML du résultat (couleur orange avant les « : », titres en gras). Modifiable directement ; toute modification ici met à jour l'aperçu de la zone 6 ci-dessous.

6. Aperçu (Rendu)

Rendu visuel du code HTML de la zone 5 : le texte avant « : » apparaît en orange, les titres de section en gras. Éditable ; les modifications ici mettent à jour le code HTML de la zone 5.

7. En-tête (Mémo)

En-têtes fixes : « Memo A2 » suivi du contenu de la zone 6, puis « Conversation » suivi du contenu de la zone 2 — reconstruites automatiquement ici à chaque fois que le bouton « Mettre en forme le résultat issu de ChatGPT » termine son traitement.

🛠️ Éditeur & Aperçus HTML

▸

8. Source HTML (Éditable)

Code HTML brut, modifiable directement. Sert de source : toute modification ici met automatiquement à jour l'Aperçu Visuel et l'Aperçu Monochrome ci-dessous.

9. Aperçu Visuel (Éditable)

Rendu visuel éditable du code HTML. Le taper ici met normalement à jour le code source ; utilisez « Coller » puis « Traiter → Aperçu Monochrome » pour un contenu collé indépendamment du code source.

10. Aperçu Monochrome (Texte coloré entre doubles crochets)

Même contenu affiché en noir uniforme, sans gras ni italique. Le texte qui était en couleur dans la source apparaît entouré de doubles crochets [[ ]] pour rester repérable.
